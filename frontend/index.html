Key EDA Insights

01

Call Duration is the Strongest Predictor

Duration accounts for ~47.7% of tree splitting importance. Customers talking for >400 seconds convert at 4× higher rate than brief calls (<150 seconds).

Feature Importance: 47.7%
02

Previous Campaign Success Boosts Conversion

When poutcome == 'success', subscription propensity spikes to ~64%. Prior positive banking relationships are high-yield targets.

Feature: poutcome — 5.1%
03

Housing Loans Cause Conversion Resistance

Clients with housing loans convert at ~7.7% vs 16.7% for those without. Constrained discretionary liquidity reduces propensity.

Feature: housing — 3.9%
04

March, September & October Show Peak Conversions

Seasonal variation is significant. Campaigns in March and October yield disproportionately higher subscription rates aligned with financial planning cycles.

Feature: month — 8.4%

Project Overview

This project is developed in strict accordance with the Darshan University Computer Engineering Department ML Project SOP (Academic Year 2025–26), approved by HOD Prof. Rupesh G Vaishnav and Dean Dr. Gopi B Sanghani.

📌
SOP Scope Note (Faculty Notice)

This project specializes in the Machine Learning Bank Marketing Project (Phase 1, Weeks 1–12). Deep Learning models (Phase 2) are intentionally omitted in favor of rigorous tabular ML depth.

Weekly Deliverables

Week 1–2: Dataset loading, EDA, Train/Test split (Zero Leakage)
Week 3: Scratch Logistic Regression (Pure NumPy, Sigmoid + BCE Loss)
Week 4: Benchmark Models — Sklearn LR, DT, RF, KNN + ROC Curves
Week 5: GridSearchCV Tuning + 5-Fold Stratified Cross-Validation
Week 6: Model Export (Joblib), Feature Importance, Artifacts
Week 7: Flask REST API + FastAPI Compatibility Backend
Week 8: Frontend Dashboard + Automated Test Suite (9/9 ✓)
